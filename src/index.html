Render Quality

        

          
          
          
          

            Honest technical note: this app runs in a browser engine (Chromium/WebGL) — there's no real DirectX 11, OpenGL, or hardware-raytraced backend to switch between here, and labeling something "Ray Tracing" without it being that would just be misleading. Soft Shadows and Ambient Occlusion above are real WebGL techniques (shadow mapping, screen-space AO) that genuinely improve how the hair and head read together — that's the actual visual goal, delivered honestly rather than under a borrowed name.

Gradient Remap

        

          
          
          
          
Remaps each pixel's brightness through this two-color gradient — a fast way to recolor while keeping the painted shading.

3D Model Export

        

          
          
          
          
glTF is the most reliable cross-engine option — Blender, Unity, Godot, and Unreal all import it directly with textures embedded in one file.


          
Experimental

          
          
          
          

            These three are hand-written against each format's documented text/ASCII structure, with no official library to build on and no way for me to validate them against real Autodesk/Pixar tooling — treat them as worth trying, not guaranteed. glTF above remains the safest bet.
          

          

            On Unreal "Groom Assets" specifically: those are for strand-simulated hair (Chaos Hair), a different asset type than the card-based hair this tool makes — card hair imports as a plain Static Mesh, which glTF/OBJ already cover correctly. "Export Guide Curves" above is the honest equivalent for strand data: it's real USD BasisCurves geometry (your actual guide points, not fabricated), which USD-aware tools can bring in as curves — the closest thing to a Groom-style workflow this app can genuinely produce.
